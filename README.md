# My Cypress Automation Project

## Project Description

This project contains automated end-to-end tests built using Cypress.

The purpose of this project is to automate testing for web applications to ensure they function correctly.

---

## Technologies Used

- Cypress
- JavaScript
- Node.js
- Git
- GitHub

---

## Installation

Clone the repository

```bash
git clone https://github.com/phemmzy85/My-Cypress-automation-project.git
```

Install dependencies

```bash
npm install
```

---

## Run Cypress

Open Cypress

```bash
npx cypress open
```

Run tests in headless mode

```bash
npx cypress run
```
